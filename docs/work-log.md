## 2026-08-26：配置 GitHub Pages 发布流程

### 完成

- 通过 ADR-0003 确定 GitHub Pages 项目站点发布方案和公开 URL。
- 增加最小权限 Pages 工作流，在 `main` 更新时检查、构建、上传并部署静态 artifact。
- 让 VitePress 通过环境变量区分本地根路径与 Pages 的 `/embed-atlas/` 仓库子路径。
- 补充 Pages 等价本地预览命令和首次启用说明。

### 判断

- 本地开发保留根路径可以减少日常操作负担；部署时显式注入仓库路径，能让同一份源码适应两种运行位置。
- Pages 部署任务使用 GitHub OIDC 和环境权限，不保存长期个人令牌。
- 首次公开部署成功前，不把公开 URL 验收项标记为完成。

### 验证

- 在 `VITEPRESS_BASE=/embed-atlas/` 下执行 `npm run check` 通过：类型检查、49 项测试、内部链接检查和生产构建全部成功。
- 生成 HTML 的静态资源、主导航和站内绝对链接均带 `/embed-atlas/` 前缀，没有发现错误的域名根路径引用。
- 本地生产预览的首页、首篇知识文章和三个工具页均可从仓库子路径加载，浏览器控制台没有错误或警告。
- CRC 工具页在 390px 测试视口下没有整页横向溢出。

### 下一动作

- 推送部署提交，在仓库 Pages 设置中选择 GitHub Actions，并从公开 URL 执行发布清单。

## 2026-08-24：完成首批十篇文章与三个工具

### 完成

- 发布文本与字节组三篇文章、CRC 参数文章以及 UART、I²C 两篇协议文章，Phase 1 首批十篇文章全部进入 `review`。
- 完成 HEX、ASCII 与字符串转换器及 CRC 计算器的规格、纯计算核心、Vue 页面、中文错误信息和工具入口。
- 建立知识库侧栏、工具箱与“嵌入式入门基础”“通信协议基础”两条连续学习路线。

### 判断

- 字符、码点、编码单元、byte 和 HEX 文本必须分层解释；调试输入采用严格解析，不静默补零或替换非法 UTF-8。
- CRC 预设必须用 Width、Poly、Init、RefIn、RefOut、XorOut 完整描述，不能只依赖“CRC-16”等简称。
- UART 和 I²C 首篇聚焦跨平台线路模型，具体 HAL、寄存器与芯片差异留到后续平台文章。

### 验证

- `npm run check` 通过：TypeScript/Vue 类型检查、43 项单元测试、内部链接检查和生产构建全部成功。
- CRC-8/SMBUS、CRC-16/ARC、CRC-16/MODBUS、CRC-32/ISO-HDLC 的 `123456789` 检查值全部匹配公开资料。
- 新增工具通过桌面和 390px 窄屏浏览器验收；UTF-8 严格错误、CRC 预设、HEX 输入、复制反馈与自定义参数状态正常，页面无横向溢出。

### 下一动作
