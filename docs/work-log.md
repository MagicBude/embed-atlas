## 2026-08-26：发布 IEEE 754 浮点数表示文章

### 完成

- 编写第 11 篇知识文章，系统解释 binary32/binary64 字段、偏置阶码、正常数、次正规数、正负零、无穷和 NaN。
- 推导十进制 `0.1` 的表示误差、binary32 的 `2^24` 整数精度边界和浮点间距变化。
- 增加浮点位模式与 byte 顺序边界，以及 C 中通过 `memcpy` 安全查看对象表示的示例。
- 接入知识库侧栏、索引、入门学习路线和公开站点冒烟检查。

### 判断

- 文章聚焦表示模型；舍入环境、异常标志和编译器优化留给后续独立主题，避免把“IEEE 754”写成无法审阅的大全。
- 不把 `sizeof(float) == 4` 当作 binary32 的充分条件，要求工程代码核对实现文档和 `<float.h>` 参数。
- 浮点解析工具应先按协议字节序还原位模式，再解释 sign、exponent 和 fraction。

### 验证

- `npm run check` 通过：58 项测试、类型检查、内部链接检查和生产构建成功。
- 桌面生产预览标题与自测入口正常，浏览器控制台无错误或警告。
- 390px 视口下四个表格没有造成整页横向溢出。
