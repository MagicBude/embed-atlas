# 长期路线图

本路线图按“成果成熟度”而不是固定日期推进。每个阶段必须达到退出条件后再扩大范围，避免同时铺开过多方向。

## Phase 0：基础规划

目标：建立可以长期延续的项目骨架。

计划成果：

- 项目愿景、目标用户和非目标范围。
- 文档、代码、注释和 Git 规范。
- 模块边界与架构决策机制。
- 知识文章和工具需求模板。
- 当前状态与跨设备、跨 AI 接续流程。

退出条件：

- 核心规划文档经过一次人工审阅。
- 网站技术方案和第一版范围明确。
- 任意新参与者能通过文档判断当前状态和下一步。

## Phase 1：最小可用网站（v0.1）

目标：公开一个内容虽少但完整、可靠、可以使用的网站。

计划成果：

- VitePress、Vue、TypeScript 网站骨架。
- 首页、知识库、工具箱、学习路线和关于页面。
- 基础搜索、响应式布局和深色模式。
- 10 篇经过模板检查的知识文章。
- 3 个经过测试的工具：
  1. 进制与位运算转换。
  2. HEX、ASCII 与字符串转换。
  3. CRC 计算器。
- 自动检查、构建和部署流程。

退出条件：

- 新用户能够独立找到文章并完成一次工具计算。
- 三个工具都有正常、边界和错误输入测试。
- 站点可以在常见桌面和手机浏览器使用。

## Phase 2：知识体系成形（v0.2）

目标：形成稳定的分类和学习路径。

计划成果：

- 基础、C 语言、MCU、外设、通信协议、RTOS、调试等主分类。
- 初学者学习路线和方向学习路线。
- 术语表、相关内容推荐和文章状态标识。
- 内容审阅与来源检查流程。
- 第一批社区贡献指南和示例。

退出条件：

- 核心分类不再频繁重排。
- 文章可以从学习路线、分类和搜索三种方式找到。
- 社区成员可以按模板独立提交一篇合格文章。

## Phase 3：工具箱扩展（v0.3）

目标：建立可持续增加工具的标准模块体系。

候选方向：

- 大小端与 IEEE 754 浮点数解析。
- UART 传输时间与波特率误差。
- 定时器、PWM、ADC 和分压计算。
- Modbus、CAN、I2C 等协议辅助工具。
- RGB565、字模和嵌入式显示转换工具。

退出条件：

- 新工具可按统一接口和模板接入。
- 核心计算、界面、文档和测试相互独立。
- 工具结果具有可公开核对的参考依据。

## Phase 4：社区与质量体系（v0.5）

目标：让项目不再依赖单个维护者。

计划成果：

- Issue 与 Pull Request 模板。
- 内容审阅者和工具维护者角色。
- 自动链接检查、术语检查和测试覆盖。
- 版本发布、废弃和迁移规则。
- 贡献者展示与公开讨论机制。

## Phase 5：稳定产品（v1.0）

目标：成为可信赖的中文嵌入式知识与工具入口。

判断标准：

- 核心分类、URL 和工具接口保持稳定。
- 有持续使用者、贡献者和明确反馈渠道。
- 内容与工具具有可执行的维护机制。
- 基础能力免费、开放并且无需登录。

## 远期探索

以下内容不进入近期承诺，只有在核心网站稳定、需求得到验证后才立项：

- PWA 与完整离线包。
- 插件系统和第三方工具接入。
- 串口、日志和协议帧分析。
- 桌面调试工作台。
- 团队协作、云同步和商业支持。

探索项进入开发前必须新增 ADR，说明用户需求、维护成本、隐私影响和对现有架构的影响。
