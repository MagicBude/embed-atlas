## 已确认决策

- 中文优先，首次出现的关键术语保留英文名称。
- 项目治理文档放在 `docs/`，正式站点内容计划放在 `site/`。
- 第一阶段使用静态网站，不引入账号、数据库和云端后端。
- 工具核心计算与 Vue 界面分离。
- 关键代码使用教材级注释，并以测试作为结果依据。
- 代码采用 MIT License，知识与文档采用 CC BY-SA 4.0。
- 首页同时服务学习、查阅和快速计算三类任务。
- 工具和文章使用独立稳定 URL，分类和筛选随内容数量渐进增强。
- 网站工程使用 Node.js 22 及以上版本、npm、VitePress 1.6.4、Vue 3.5.41 和 TypeScript 5.9.3。

## 当前风险

- 早期分类过细会产生大量空页面。
- 工具数量增长过快会降低测试与解释质量。
- 不同资料对协议参数和术语的定义可能不一致，需要明确来源。
- “教材级注释”如果被理解为逐行解释，会造成噪声和维护负担；应遵守注释规范中的边界。
- VitePress 1.6.4 当前依赖的 Vite 5 存在仅开发服务器相关的已知安全公告，且稳定兼容范围内暂无修复版本；本地命令已限制监听 `127.0.0.1`，后续跟踪 VitePress 2 稳定版升级。
