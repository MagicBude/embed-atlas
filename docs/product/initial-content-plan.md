# Phase 1 首批知识内容计划

## 1. 目标

Phase 1 的 10 篇文章不追求覆盖整个嵌入式领域，而是围绕前三个在线工具建立一条可连续学习、可以互相引用的基础路径。每篇文章都要解决一个明确问题，并为后续 C 语言、协议和 MCU 内容提供稳定前置知识。

## 2. 选题原则

- 优先解释跨芯片、跨语言、跨平台仍然成立的基础概念。
- 每个首批工具至少关联一篇原理文章。
- 相邻文章存在清楚的前置关系，但单篇也能通过搜索独立阅读。
- 不把多个大主题压进一篇“大全”，避免文章无法审阅和维护。
- 首批状态可以从 `draft` 进入 `review`，只有来源、示例和关键结论复核后才标记 `verified`。

## 4. 建议发布顺序

### 第一组：数值与位模式

1. 整数、进制与位模式。
2. 二进制补码与有符号整数范围。
3. 位运算、位掩码与寄存器字段。
4. C 定宽整数、提升与溢出边界。

完成后，第一个转换器拥有从入门原理到 C 平台差异的完整入口。

### 第二组：文本与字节

1. 字节、字符、编码与字符串。
2. HEX 文本与原始二进制数据。
3. 字节序与多字节整数。

这一组为第二个工具和后续固件文件工具建立共同术语。

### 第三组：校验与协议

1. CRC 模型参数与标准检查值。
2. UART 帧格式、波特率与实际传输位数。
3. I2C 7 位地址与读写位。

CRC 文章直接服务第三个工具；UART 和 I2C 用于验证知识库能从数据表示平稳扩展到通信协议。

## 5. 每篇文章的完成条件

- frontmatter 元数据符合内容系统约定。
- 开头说明解决的问题和所需前置知识。
- 关键术语、公式、单位、范围和例子可以独立核对。
- 区分通用原理、语言规则、平台实现和工程建议。
- 至少解释三个常见误区或故障现象。
- 与相关工具、前置文章和后续文章建立链接。
- 关键事实引用标准或官方资料，没有大段复制原文。
- 完成标题层级、桌面、窄屏、深色模式和构建检查。
