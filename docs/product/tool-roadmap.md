# 在线工具路线图

本文件管理工具方向与优先级，不代表固定发布日期。单个工具开发前仍必须使用 `docs/templates/tool-spec.md` 编写需求和测试向量。

## 1. 入选标准

候选工具按以下维度评估：

| 维度 | 说明 |
| --- | --- |
| 使用频率 | 嵌入式工程师是否经常手算、查表或临时写脚本 |
| 教学价值 | 是否能自然连接一篇重要知识文章 |
| 可验证性 | 是否存在标准、官方公式或公开参考向量 |
| 浏览器适配 | 是否可以安全、稳定地在本地浏览器完成 |
| 维护成本 | 芯片预设、标准版本和兼容性是否容易持续维护 |
| 差异价值 | 中文解释、代码生成或错误分析是否能明显优于普通计算器 |

高频、易验证、低维护并且有教学价值的工具优先。

## 2. v0.1：基础数据工具

目标：验证工具模块、输入解析、结果展示和测试体系。

1. 进制与位运算转换器。
2. HEX、ASCII 与字符串转换器。
3. CRC 计算器。

这三个工具分别覆盖数值、文本/字节和协议算法三种核心数据类型。

## 3. v0.2：工程表示与速查

候选顺序：

1. 大小端与字节交换转换器。（已实现）
2. IEEE 754 浮点数解析器。
3. 补码与有符号整数转换器。
4. UART 帧时间计算器。
5. XOR、SUM、LRC 校验和工具。
6. 寄存器位域提取器。

重点是把“数值、内存表示、线路字节序”解释清楚。

## 4. v0.3：通信协议工具

候选方向：

- UART 波特率误差与寄存器参数。
- I2C 7 位/8 位地址转换。
- SPI CPOL/CPHA 模式速查。
- Modbus RTU 报文生成、解析和 CRC 验证。
- CAN 位时序和采样点。
- RS-485 帧时间与偏置计算。

协议工具必须明确标准范围和平台差异，不把厂商特例写成通用规则。

## 5. v0.4：MCU 与固件工具

候选方向：

- 通用定时器 Prescaler/Period 计算。
- PWM 频率、占空比和分辨率。
- ADC 码值、电压和 LSB。
- 看门狗超时。
- RTC 晶振漂移。
- Flash 擦写寿命估算。
- C 结构体对齐与填充可视化。

芯片族预设作为参数包接入，核心公式保持通用。

## 6. v0.5：硬件与传感器

候选方向：

- 欧姆定律与功率。
- 分压与 ADC 输入。
- LED 限流电阻。
- I2C 上拉电阻。
- RC 滤波与时间常数。
- NTC 热敏电阻。
- 电池寿命与工作周期。

结果应逐步加入容差、功耗和安全余量提示。

## 7. v0.6：显示与固件文件

候选方向：

- RGB888 / RGB565 转换与颜色选择。
- 图片转 RGB565 或单色位图数组。
- TFT 带宽和帧率估算。
- Intel HEX、S-Record 与 BIN 转换。
- HEX 文件查看与差异比较。
- 二进制转 C 数组。

所有文件默认只在浏览器本地处理，并设置清楚的大小限制。

## 8. 远期工具

需要单独 ADR 和兼容性研究：

- Web Serial 串口终端。
- Web Bluetooth、WebUSB 与 WebHID。
- 波形和日志分析。
- 指令模板与批量发送。
- 调试会话记录和桌面工作台。

这些工具会引入权限、设备、长连接和浏览器兼容问题，不能直接套用普通计算器模块。

## 9. 明确不追求

- 为了增加数量而重复开发已有的通用 JSON、UUID、JWT 等工具。
- 在没有可靠依据时提供看似精确的工程结果。
- 第一版就支持所有芯片、协议和厂商预设。
- 把“即将推出”的空工具长期展示给用户。
