# 进制与位运算转换器

把寄存器值、协议字段和位掩码转换为二进制、八进制、十进制与十六进制，并在明确位宽下执行逐位运算。输入只在当前浏览器中处理，不会上传。

## 怎样理解同一个位模式

固定宽度整数需要区分“位模式”和“如何解释它”。例如 8 位 `0xFF` 的每一位都是 `1`：

- 按无符号整数解释，它是 `255`。
- 按 8 位二进制补码有符号整数解释，它是 `-1`。

工具会同时显示两种十进制结果，不要求你在输入前先选“有符号”或“无符号”。二、八、十六进制输入表示原始位模式；需要输入负数时请选择十进制。

## 运算规则

所有运算都限制在所选的 8、16、32 或 64 位内：

- AND、OR、XOR 对相同位置的位进行组合。
- NOT 只反转所选位宽内的位，不会显示无限多个前导 `1`。
- 左移在低位补 `0`，超出当前位宽的高位会被舍弃并显示警告。
- 逻辑右移把 A 当作无符号位模式，高位补 `0`。
- 算术右移先按补码解释 A，高位补符号位。

::: warning 不等同于所有 C/C++ 表达式
本工具采用明确的固定宽度规则。C 和 C++ 中整数提升、有符号右移、溢出以及具体整数类型还会受到语言标准、编译器和目标平台影响。用于固件前，请结合实际类型和编译器行为确认。
:::

## 输入格式

- 可选择二、八、十或十六进制，不自动猜测进制。
- 支持与所选进制匹配的 `0b`、`0o`、`0x` 前缀。
- 支持数字之间的下划线，例如 `0xFF_FF`。
- 负号只用于十进制输入。
- 输入超出当前位宽时会报错，不会静默截断。

## 验证状态

纯计算核心与 Vue 界面分离。当前核心已经使用 29 个单元测试覆盖典型转换、边界值、64 位精度、非法字符、补码、截断和七种位运算。

固定宽度有符号和无符号转换遵循 ECMAScript `BigInt.asIntN` 与 `BigInt.asUintN` 的定义。完整需求、错误模型和测试向量记录在项目开发文档中。
