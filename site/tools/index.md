# 在线工具箱

工具默认在浏览器本地运行。每个工具都会说明输入格式、单位、算法范围、边界条件和验证依据，而不只显示一个最终数字。

## v0.1 首批工具

| 工具 | 解决的问题 | 状态 |
| --- | --- | --- |
| [进制与位运算转换器](./base-bit-converter) | 在二、八、十、十六进制之间转换并观察位模式 | 可使用，核心已测试 |
| [HEX、ASCII 与字符串转换器](./hex-text-converter) | 在文本、字符编码和原始字节之间转换 | 可使用，核心已测试 |
| [CRC 计算器](./crc-calculator) | 使用明确的 CRC 模型参数计算和验证校验值 | 可使用，四个公开检查值已测试 |

## v0.2 工程表示工具

| 工具 | 解决的问题 | 状态 |
| --- | --- | --- |
| [大小端与字节交换转换器](./endianness-converter) | 在 byte 序列与大端/小端无符号整数之间转换 | 可使用，支持 1～8 byte |

## 工具质量要求

- 核心计算与界面分离。
- 覆盖正常值、边界值、非法输入和公开参考向量。
- 带单位的数据明确标注单位。
- 提供一键示例、复制反馈和具体错误提示。
- 关联完整原理文章、代码示例和常见错误。

::: tip 为什么按顺序扩展？
首批三个工具已经验证统一模块设计；后续继续按使用频率、教学价值和可验证性逐个加入 IEEE 754、UART、Modbus、CAN 和 MCU 计算工具。
:::
