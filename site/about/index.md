# 关于 EmbedAtlas

EmbedAtlas（嵌入式图谱）是面向中文嵌入式工程师的开源知识库与在线工具箱。

## 我们希望做到

- 用准确、自然的中文解释嵌入式知识。
- 把原理文章、工程速查和在线工具连接起来。
- 让计算结果能够通过公式、来源和测试进行验证。
- 让初学者知道学习顺序，让工程师能够快速解决现场问题。
- 保持模块化，让不同方向可以独立建设和维护。
